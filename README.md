## About

I build custom Android ROMs for Infinix phones. Device trees, vendor trees, kernels, recoveries, and the OTA plumbing that holds it all together — mostly on the MediaTek Helio G99 (MT6789) platform.

No big team, no company. Just me, a build machine, and phones that deserve better software than they shipped with.

---

## Currently

- **Android 17 (LineageOS 24)** bring-up for the Infinix HOT 40 Pro (X6837)
- Maintaining Android 16 trees for the HOT 40 Pro and NOTE 12 2023 (X676C)
- OTA update infrastructure for the Infinity X project
